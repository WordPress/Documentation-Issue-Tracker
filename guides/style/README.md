# WordPress Style Guides

This index links to every style reference the Documentation team already maintains, including the Documentation Style Guide, the Docs Team Handbook guides, and the coding and inline documentation standards. Following them keeps your contribution consistent with the rest of WordPress documentation and makes it faster to review.
